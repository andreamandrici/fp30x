# Modalità Tastiera e Suoni (Toni)
## Dual Mode (Sovrapposizione): Tieni premuto un tasto categoria (es. PIANO) e premi contemporaneamente un altro tasto categoria (es. OTHER).
## Split Point (Punto di divisione): Tieni premuto SPLIT + premi la nota desiderata per spostare il taglio.
## Twin Piano On/Off: Tieni premuto FUNCTION +
